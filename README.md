## 💡 어려웠던 부분과 해결

- **카카오맵 API 적용 및 봉사 장소 표시**

**어려움**: 처음으로 **카카오맵 API**를 적용하면서 지도를 불러오고, 봉사 장소를 정확하게 표시하는 데 어려움을 겪었습니다. 특히, 지도 위에 마커를 표시하고, 여러 위치를 동적으로 불러오는 로직을 구현하는 부분이 복잡하게 느껴졌습니다.

**해결 방법**: 카카오맵 API 문서를 꼼꼼히 살펴보며 다양한 예제 코드를 분석하고, API를 호출하는 방식과 동적으로 데이터를 처리하는 방법을 학습했습니다. 또한, 구글링을 통해 다른 개발자들의 해결 방법을 참고하고, 테스트를 거쳐 장소 마커와 정보를 정확하게 지도 위에 표시할 수 있었습니다.

- **무한 스크롤 및 페이징 처리**

**어려움**: 봉사와 멘토링 리스트를 조회할 때, 데이터가 많아 한 번에 모든 정보를 불러오면 성능이 저하되는 문제가 발생했습니다. 이를 해결하기 위해 **무한 스크롤**과 **페이징**을 구현해야 했는데, 처음으로 페이징을 적용하면서 데이터가 중복되거나 제대로 로드되지 않는 오류가 자주 발생했습니다.

**해결 방법**: Android의 RecyclerView와 ScrollListener를 활용해 스크롤 이벤트를 감지하고, 필요한 데이터만 불러오도록 로직을 최적화했습니다. 또한, 백엔드에서 페이징 처리를 위해 Spring Boot와 MyBatis를 사용해 데이터를 효율적으로 가져오는 쿼리를 작성하고, 클라이언트와 서버 간의 데이터 흐름을 최적화했습니다. 이를 통해 성능 문제를 해결하고 사용자 경험을 향상시켰습니다.

## 💡 성장한 부분

- **안드로이드 개발에 대한 깊은 이해**
    
    이번 프로젝트를 통해 **Android Studio**와 **Kotlin**을 사용해 실질적인 안드로이드 앱 개발 경험을 쌓을 수 있었습니다. 특히, 지도 API 적용, 무한 스크롤 등 복잡한 기능을 직접 구현하면서 안드로이드 개발에 대한 자신감이 생겼고, 사용자 중심의 앱을 설계하는 방법을 익히게 되었습니다.
    
- **API 통합 및 데이터 처리 능력 향상**
    
    카카오맵 API와의 연동을 비롯해, 백엔드와의 통신에서 데이터 처리를 최적화하는 과정을 통해 **API 통합** 능력이 크게 향상되었습니다. API 요청과 응답을 효율적으로 관리하고, 클라이언트와 서버 간의 데이터를 안정적으로 주고받는 방법을 깊이 이해하게 되었습니다.
